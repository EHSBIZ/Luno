# وب‌سایت Luno

سایت معرفی فارسی، راست‌چین و واکنش‌گرا؛ بدون نیاز به فریم‌ورک یا build و آماده GitHub Pages.

## انتشار
1. فایل‌های این پوشه را در ریشه مخزن GitHub (مثلاً `Luno-Website`) قرار دهید.
2. به Settings → Pages بروید.
3. در Build and deployment گزینه Deploy from a branch را انتخاب کنید.
4. Branch را `main` و پوشه را `/ (root)` قرار دهید و Save کنید.
5. پس از انتشار، آدرس سایت در همین صفحه نشان داده می‌شود.

## افزودن اسکرین‌شات
عکس‌ها را در `screenshots/` قرار دهید. سپس فایل `screenshots/images.json` را ویرایش کنید و نام فایل‌ها را در آرایه وارد کنید. دو تصویر نمونه `dashboard.png` و `products.png` را با نام تصاویر خود جایگزین کنید یا فایل‌ها را با همین نام قرار دهید. فرمت PNG/JPG/JPEG/WEBP قابل استفاده است.

نمونه:
```json
[{"file":"dashboard.png","title":"داشبورد اصلی"},{"file":"sales.jpg","title":"فاکتور فروش"}]
```

## ویرایش اطلاعات
متن‌ها و اطلاعات تماس در `index.html`، ظاهر در `style.css`، منطق گالری و منو در `script.js` و لوگو در `assets/` است. شماره‌ها و آیدی تلگرام مطابق اطلاعات قبلی وارد شده‌اند.
